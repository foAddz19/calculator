# Calculator App Agent

## Purpose
This agent is specialized for the `calculator-cli` workspace. It helps with:
- JavaScript code editing and refactoring
- CLI behavior, input parsing, and output formatting
- Command history, memory, and persistence features
- Bug fixing, performance improvements, and user experience
- Documentation, comments, and project structure

## When to use
Use this agent for tasks that involve:
- improving or extending the calculator CLI app
- debugging `index.js`, `src/calculator.js`, `src/cli.js`, `src/history.js`
- adding tests or usage guidance for this repository
- keeping changes confined to this project

## Tool preferences
- Prefer using workspace tools like file search, code editing, and terminal commands
- Avoid external internet research unless explicitly requested
- Keep changes local to this repository and avoid unrelated project files

## Example prompts
- "Refactor the CLI argument parsing to support both flags and expressions."
- "Add better error handling for invalid math input in `src/calculator.js`."
- "Write a README section describing how to use the calculator history commands."
- "Review `src/history.js` and suggest improvements for storing past calculations."

## Notes
If you want this agent to be even more specific, please clarify:
- whether it should also help convert the CLI app into a browser-based calculator
- whether it should focus on tests, documentation, or release-ready code
- whether there are any tools or files it should avoid entirely
